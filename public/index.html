RO-Crate Excel Server

A small HTTP service that converts an Excel workbook into RO-Crate JSON-LD using ro-crate-excel.

POST/convert

Upload a single .xlsx workbook as multipart/form-data in a field named file. The response body is the crate as application/ld+json.

Request

Field Type Notes
file file (.xlsx) Required. The RO-Crate metadata spreadsheet.

Example

curl -X POST \
  -F "file=@ro-crate-metadata.xlsx" \
  https://ro-crate-excel-api.light.garden/convert

Add ?report=1 to receive an application/json envelope { "crate": { ... }, "warnings": [ ... ] } instead of the bare crate. Each warning has a source, a level (warning or error), and a message.

Responses

Status Meaning
200 RO-Crate JSON-LD (application/ld+json).
400 No file, a non-.xlsx file, or a workbook that could not be parsed.
413 The uploaded file exceeds the size limit.

    POST/validate

    Validate an RO-Crate JSON-LD document against the RO-Crate specification. Send the crate as the request body with a Content-Type of application/json or application/ld+json.

    Example

    curl -X POST \
  -H "Content-Type: application/ld+json" \
  --data-binary @ro-crate-metadata.json \
  https://ro-crate-excel-api.light.garden/validate

    Response

    200 with a JSON body { "valid": boolean, "results": [ ... ] }. Each result has an id, a status of success, warning, or error, a message, and a spec clause. valid is false when any result is an error. A body that is missing or not a JSON object returns 400.
